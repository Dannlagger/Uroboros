# versions

Carpeta para guardar versiones y archivos básicos.

Estructura sugerida:
- versions/README.md  (esta página)
- versions/.gitkeep    (mantiene la carpeta en git si está vacía)
- versions/assets/     (logos, fuentes, imágenes base)

Este repositorio principal se ha limpiado para iniciar el sitio desde 0. El respaldo completo del estado anterior está en la rama `pre-wipe`.
